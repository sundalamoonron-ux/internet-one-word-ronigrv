The internet in one word: **brainrot**. `main.py` writes that single word to `/output/entry.txt` — 8 characters, no spaces or punctuation, funny by itself and true of the whole internet. The word was picked by a pairwise tournament of 10 candidates.

## Run it

```sh
python3 main.py
```
